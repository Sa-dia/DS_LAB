
# Data Structures Lab
## About This Repository

This repository contains source codes and practical implementations of fundamental data structures and algorithms covered in the Data Structures Lab.

The objective is to help students understand data structures through hands-on programming exercises.

## Software Requirements

Before running the programs, install the following:

- **Code Editor:** Visual Studio Code (VS Code)
- **Compiler:** GCC/G++
- **Operating System:** Windows, Linux, or macOS

## How to Download the Repository

### Method 1: Download as ZIP

1. Open this GitHub repository.
2. Click the green **Code** button.
3. Select **Download ZIP**.
4. Extract the downloaded ZIP file.
5. Open the extracted folder in VS Code.

### Method 2: Clone Using Git

If Git is installed on your computer, open the terminal and execute:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd YOUR_REPOSITORY_NAME
```

## How to Run a C++ Program

### Step 1: Open the Project

Open the downloaded repository folder in VS Code.

### Step 2: Open the Terminal

Select **Terminal → New Terminal** in VS Code.

### Step 3: Navigate to the Experiment Folder

For example:

```bash
cd Lab-01
```

### Step 4: Compile the Program

Suppose your source file is named `main.cpp`.

```bash
g++ main.cpp -o main
```

### Step 5: Execute the Program

**For Windows:**

```bash
.\main.exe
```

**For Linux/macOS:**

```bash
./main
```

## How to Run a C Program

For C source files, use the following commands.

**Compile:**

```bash
gcc main.c -o main
```

**Execute on Windows:**

```bash
.\main.exe
```

**Execute on Linux/macOS:**

```bash
./main
```

## Important Instructions

1. Download or clone the repository before starting the lab exercises.
2. Read and understand the source code before execution.
3. Compile and execute each program using the appropriate compiler.
4. Modify input values to test different cases.
5. Practice implementing the data structures independently.

## Troubleshooting

| Problem | Possible Solution |
|---------|-------------------|
| `g++ is not recognized` | Install GCC/G++ and configure the PATH environment variable. |
| `No such file or directory` | Check the current directory and source file name. |
| Compilation error | Check the syntax and program code. |
| Program does not execute | Make sure compilation completed successfully. |
