## ⚙️ Software Requirements

Before running the programs, make sure you have installed:

| Software | Purpose |
|---|---|
| 💻 Visual Studio Code | Code editor |
| 🔧 GCC/G++ | C/C++ compiler |
| 🐙 Git | Repository cloning (optional) |

## ⬇️ How to Download the Repository

### 🔹 Method 1: Download ZIP

1. Open this GitHub repository.
2. Click the green **`Code`** button.
3. Select **`Download ZIP`**.
4. Extract the downloaded ZIP file.
5. Open the extracted folder using VS Code.

### 🔹 Method 2: Clone Using Git

Open your terminal and execute:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the repository:

```bash
cd YOUR_REPOSITORY_NAME
```

## 🚀 How to Run the Programs

### 🟢 Step 1: Open the Project

Open the downloaded repository folder in Visual Studio Code.

### 🟢 Step 2: Open the Terminal

Go to:

`Terminal → New Terminal`

### 🟢 Step 3: Navigate to the Lab Folder

For example:

```bash
cd Lab-01
```

### 🟢 Step 4: Compile the C++ Program

Suppose your source file is `main.cpp`.

```bash
g++ main.cpp -o main
```

### 🟢 Step 5: Execute the Program

**🪟 Windows:**

```bash
.\main.exe
```

**🐧 Linux/macOS:**

```bash
./main
```

### 📌 For C Programs

**Compile:**

```bash
gcc main.c -o main
```

**Execute on Windows:**

```bash
.\main.exe
```

**Execute on Linux/macOS:**

```bash
./main
```

## 💡 Important Instructions

- 📖 Read and understand the source code before execution.
- ⌨️ Practice writing the programs independently.
- 🔍 Test programs with different input values.
- 🛠️ Identify and correct compilation and logical errors.
- 🧠 Understand the algorithm and its time complexity.
- 💻 Complete the lab exercises regularly.

## ❓ Troubleshooting

| Problem | Solution |
|---|---|
| `g++ is not recognized` | Install GCC/G++ and configure PATH. |
| `No such file or directory` | Check the directory and filename. |
| Compilation error | Check the syntax and code. |
| Program does not execute | Ensure compilation was successful. |
